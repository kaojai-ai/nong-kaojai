# Nong-KaoJai (KJ Toys)

Small playful assets, Codex pets, and fun widgets for Kaojai AI.

This repository is a home for lightweight experiments that make internal tools feel more alive without becoming product code. Each toy should live in its own folder with a short README, install instructions, and any assets needed to use it.

## Toys

| Toy | Description |
| --- | --- |
| [`codex-pet`](./codex-pet) | Nong Kaojai, a custom Codex pet based on the Kaojai.ai chat-bubble mascot. |

## Repository Guidelines

- Keep each toy self-contained.
- Include install or usage steps in the toy folder.
- Store generated or binary assets only when they are needed to use the toy.
- Keep experiments small, readable, and easy to remove.
